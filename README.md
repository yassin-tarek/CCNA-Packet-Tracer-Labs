# CCNA Packet Tracer Labs

Welcome to my **CCNA Packet Tracer Labs** repository!

This repository documents my hands-on networking practice while studying for the Cisco Certified Network Associate (CCNA) certification. It contains Packet Tracer labs, configuration files, network topologies, and larger networking projects covering a wide range of CCNA topics.
